# النسر للتجارة – Al Nesr Trading

## التشغيل
- ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
- فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root).
- افتح رابط Pages من Chrome ثم اختر Install app أو Add to Home screen.
- يجب فتح التطبيق أول مرة مع اتصال إنترنت حتى يتم تخزين ملفات الواجهة للاستخدام دون اتصال.

## تنبيه مهم
هذه نسخة أولية عملية وليست نظامًا محاسبيًا معتمدًا أو جاهزًا للاستخدام التجاري دون اختبار. التخزين محلي في المتصفح فقط. لا تمسح بيانات المتصفح. صدّر نسخة احتياطية JSON بانتظام واحفظها خارج الجهاز. كلمة المرور الافتراضية 1234 ويجب تغييرها.

## الوظائف الموجودة
المنتجات، حركات المخزون، العملاء، الموردون، تسجيل مشتريات ومبيعات، مصروفات، حركات خزنة، ملخصات وتقارير إجمالية، فواتير طباعة/PDF، إعدادات النشاط، تغيير كلمة المرور، نسخة احتياطية واستعادة، وتصدير CSV للمنتجات.

## حدود النسخة
- لا يوجد مزامنة بين الأجهزة أو مستخدمون متعددون.
- لا يوجد ربط دفع أو فواتير ضريبية إلكترونية.
- بعض تقارير الفترات التفصيلية وتصدير كل الجداول إلى Excel، وربط الديون والتحصيلات الجزئية المتعددة، تحتاج استكمالًا واختبارات إضافية.
- كلمة المرور داخل التطبيق المحلي حماية بسيطة وليست تشفيرًا للبيانات.
- لا تعتمد على أرقام الأرباح والخزنة قبل مراجعة كل السيناريوهات المحاسبية عمليًا.
